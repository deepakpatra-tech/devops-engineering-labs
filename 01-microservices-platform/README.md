# CloudX Microservices Platform

A production-oriented cloud-native microservices application designed to demonstrate modern DevOps engineering practices.

## Architecture

- Frontend application
- Flask-based backend microservices
- PostgreSQL database
- Docker containerization
- Kubernetes orchestration

## DevOps Implementation

- AWS cloud infrastructure
- Terraform infrastructure provisioning
- Ansible configuration management
- Jenkins and GitHub Actions CI/CD
- Kubernetes deployment and service networking
- Prometheus and Grafana monitoring
- ELK Stack centralized logging
- OpenTelemetry distributed tracing
- DevSecOps and automated vulnerability scanning

## Project Goals

Build a scalable, secure, automated, observable, and maintainable application deployment platform following production engineering practices.
